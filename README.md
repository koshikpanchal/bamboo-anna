# Bamboo Anna Website

## Development

- `npm run dev`
- `npm run build`
- `npm run preview`

## SEO and performance

- Set `VITE_SITE_URL` in your environment (or `.env`, see `.env.example`) to the production domain.
  - Used for canonical URLs and the sitemap.
- Per-page SEO lives in `src/site/seo/Seo.tsx` and is configured in each page.
- Structured data:
  - Organization + WebSite on the homepage
  - Product schema on product detail pages
- Sitemap and robots:
  - `public/robots.txt`
  - `public/sitemap.xml` is generated by `scripts/generate-sitemap.mjs` during build
- Add new product slugs to `scripts/generate-sitemap.mjs` when catalogue items change.

## Homepage scroll animations

The Bamboo Anna homepage uses data-attribute driven, progressively-enhanced scroll animations:

- `data-anim="hero"`: initial hero reveal (500ms, ease-out)
- `data-anim="count"`: count-up stats when in view (runs once)
- `data-anim="reveal"`: section/card reveals via `IntersectionObserver`
- `data-anim="pin-story"` / `data-anim="scroll-craft"` / `data-anim="journey"`: GSAP `ScrollTrigger` pins/progress (desktop only)

### Toggle animations (no code changes)

Use query params while running `npm run dev`:

- Disable all: `/?anim=0`
- Disable hero: `/?animHero=0`
- Disable counts: `/?animCounts=0`
- Disable tags: `/?animTags=0`
- Disable mini story pin: `/?animStory=0`
- Disable Scroll craft pin/explode: `/?animCraft=0`
- Disable journey progress line: `/?animJourney=0`
- Disable impact gradient shift: `/?animImpact=0`

### Reduced motion + mobile behavior

- `prefers-reduced-motion: reduce` disables pins/explode (shows static content)
- Mobile/small screens disable pins to keep scroll simple and avoid overflow

### Testing checklist

- Build: `npm run build`
- Lighthouse: Chrome DevTools > Lighthouse (Performance + SEO)
- GTmetrix: run the URL once deployed (check LCP, CLS, and total JS payload)
- Motion: verify smooth scroll on home and no horizontal overflow on mobile
